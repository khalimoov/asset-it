УЧЁТ ИТ-ОТДЕЛА — ПАКЕТ ОБНОВЛЕНИЯ ДЛЯ DOCKER (без интернета)
==========================================================

Пакет обновляет уже установленное приложение. Внутри только новый код —
страница и сервер, несколько мегабайт. Python, библиотеки и Tesseract берутся
из образа, который уже загружен на сервере, поэтому интернет не нужен и
полный офлайн-пакет (~230 МБ) везти не надо.

  app/                 новый код: web/ и server/
  Dockerfile.update    сборка образа поверх установленного
  update.sh            обновление одной командой
  VERSION              номер версии
  ОБНОВЛЕНИЕ.txt       этот файл

Подходит, только если приложение уже стоит из офлайн-пакета (install.sh).
Если в новой версии другие библиотеки, update.sh это увидит, ничего не
тронет и попросит полный офлайн-пакет.


КАК ОБНОВИТЬ
------------

  1. Скопируйте архив на сервер и распакуйте рядом с установкой:

       sudo tar -xzf asset-it-update-<версия>.tar.gz -C /opt/asset-it
       cd /opt/asset-it/asset-it-update-<версия>

  2. Обновите:

       sudo sh update.sh

     Скрипт сам найдёт папку установки (где docker-compose.yml). Если не
     найдёт — укажите её:  sudo sh update.sh /opt/asset-it/asset-it-docker-offline

     По шагам: проверка библиотек → копия базы (backup-before-<версия>-….dump
     в папке установки) → прежний образ сохраняется как asset-it:before-<версия>
     → сборка нового образа → перезапуск только контейнера app → ожидание, пока
     откроется страница новой версии. В конце напишет «Готово: работает версия …».

  3. Откройте приложение в браузере и обновите страницу (Ctrl+F5). Номер
     версии виден внизу бокового меню.

Простой — около минуты, пока перезапускается app. База и документы не
трогаются, схема базы доводится до новой версии при старте сама.


ЕСЛИ ЧТО-ТО НЕ ТАК — ОТКАТ
-------------------------

  Команды отката update.sh печатает в конце, с точными именами. В общем виде
  (из папки установки):

       docker tag asset-it:before-<версия> asset-it:latest
       docker compose up -d --no-deps app
       docker compose exec -T db pg_restore -U asset_it -d asset_it -c < backup-before-<версия>-….dump

  Код и базу откатывайте вместе: новая версия могла перестроить данные под себя.

  Старые образы для отката место занимают немного, но со временем их можно
  убрать:   docker image rm asset-it:before-<старая версия>
