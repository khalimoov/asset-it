УЧЁТ ИТ-ОТДЕЛА — УСТАНОВКА НА СЕРВЕР БЕЗ ИНТЕРНЕТА
===================================================

Всё нужное лежит в этой папке. Интернет не понадобится ни разу:
библиотеки Python уже скачаны в папку wheels.


ЧТО ДОЛЖНО БЫТЬ НА СЕРВЕРЕ
--------------------------

  * Windows 64 бита
  * PostgreSQL 18 — установлен, служба запущена
  * Python 3.14 (64 бита) — при установке галочка "Add python.exe to PATH"

Больше ничего ставить не нужно.


УСТАНОВКА — ТРИ ШАГА
--------------------

  1. Скопируйте всю папку на сервер, например в  C:\AssetIT

  2. Запустите  install.bat
     Он создаст окружение, поставит библиотеки из папки wheels,
     спросит пароль суперпользователя PostgreSQL (тот, что задавали
     при установке PostgreSQL) и создаст базу.

     Пароль суперпользователя нигде не сохраняется — он нужен только
     чтобы создать базу. Пароль приложения программа придумает сама
     и запишет в server\.env

  3. Запустите  start.bat

     При первом запуске в окне появится логин и пароль администратора.
     Они же продублированы в файле  server\FIRST_LOGIN_asset_it.txt

     Логин:  admin

     Сразу войдите и смените пароль: Сотрудники ИТ -> карточка admin ->
     поле "Пароль". После этого файл FIRST_LOGIN можно удалить.


ЧТОБЫ ЗАХОДИЛИ ДРУГИЕ СОТРУДНИКИ
--------------------------------

  Запустите  open-firewall.bat  от имени администратора
  (правой кнопкой -> "Запуск от имени администратора").
  Он откроет порт 8000 для локальной сети.

  Дальше сотрудники заходят в браузере по адресу:

      http://имя-сервера:8000
      или
      http://192.168.x.x:8000        (адрес сервера в сети)

  Узнать адрес сервера:  в командной строке наберите  ipconfig

  Ничего устанавливать сотрудникам не нужно — только браузер.


РАСПОЗНАВАНИЕ НАКЛАДНЫХ
-----------------------

  Нужно, чтобы вебка читала сканы накладных. Ставится один раз,
  интернет не нужен - установщик лежит в папке tesseract.

  Запустите  install-ocr.bat  от имени администратора.

  Словари русского языка уже в комплекте: server	essdata.
  Отдельно ничего качать не надо.

  Проверить: раздел "Накладные" - вверху будет написано
  "Распознавание готово: tesseract 5.4.0, языки - eng, rus".

  Накладные, напечатанные из программы, читаются точно и без распознавания -
  у них внутри есть текстовый слой. Распознавание нужно только для сканов.


КАК ОСТАНОВИТЬ СЕРВЕР
---------------------

  Запущен из start.bat:  Ctrl+C в его окне.

  В любом другом случае - stop.bat. Он гасит задачу автозапуска
  и снимает процесс, который слушает порт, как бы тот ни был запущен.

  Вручную, если нужно:
      netstat -ano | findstr :8000      - узнать номер процесса
      taskkill /F /PID номер            - снять его


ЧТОБЫ СЕРВЕР ПОДНИМАЛСЯ САМ ПОСЛЕ ПЕРЕЗАГРУЗКИ
----------------------------------------------

  Запустите  autostart-install.bat  от имени администратора.
  Сервер будет стартовать вместе с Windows, без окна.

  Запустить прямо сейчас, не перезагружаясь:
      schtasks /run /tn "Asset IT"

  Остановить:         stop.bat  или  schtasks /end /tn "Asset IT"
  Убрать автозапуск:  autostart-remove.bat


РЕЗЕРВНЫЕ КОПИИ
---------------

  backup-db.bat  выгружает всю базу в один файл в папку backup.
  Запускайте хотя бы раз в неделю, а файл кладите не на этот же диск.

  Восстановление из копии:
      pg_restore -h localhost -U asset_it -d asset_it -c "файл.dump"


ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
------------------------

  "Python не найден"
      Python не добавлен в PATH. Переустановите его с галочкой
      "Add python.exe to PATH" либо запускайте install.bat так:
      "C:\Python314\python.exe" -m venv .venv  — и дальше по install.bat

  "Библиотеки установить не удалось"
      На сервере Python не 3.14 или не 64-битный. Колёса в папке wheels
      собраны именно под Python 3.14 Windows 64. Проверить версию:
      python -c "import sys; print(sys.version)"

  "Не удалось подключиться к PostgreSQL"
      Служба PostgreSQL не запущена или пароль суперпользователя другой.
      Проверить службу: services.msc -> postgresql-x64-18 -> Запустить

  Сотрудники не открывают страницу
      Не открыт порт: запустите open-firewall.bat от администратора.
      Проверьте, что на сервере страница открывается по http://localhost:8000

  Забыт пароль администратора
      Удалите строку пароля в базе и перезапустите сервер:
      он снова создаст admin с новым паролем. Команда:
      "C:\Program Files\PostgreSQL\18\bin\psql.exe" -U asset_it -d asset_it
          -c "delete from staff where login = 'admin'"


ЧТО ГДЕ ЛЕЖИТ
-------------

  install-ocr.bat          установка распознавания накладных
  it-inventory.html        вся страница приложения, один файл
  server\app.py            сервер: доступ, права, работа с базой
  server\serve.py          запуск рабочего сервера (waitress)
  server\setup_db.py       создание базы, вызывается из install.bat
  server\schema.sql        таблицы
  server\.env              настройки и пароль базы  (НЕ ПОКАЗЫВАТЬ НИКОМУ)
  server\README.md         описание прав, API и устройства сервера
  wheels\                  библиотеки Python для установки без интернета
  tesseract\               установщик движка распознавания
  server	essdata\         словари русского языка
  backup\                  сюда backup-db.bat кладёт копии базы


ОБНОВЛЕНИЕ НА НОВУЮ ВЕРСИЮ
--------------------------

  1. Остановите сервер: stop.bat
     (или Ctrl+C в его окне, если запускали через start.bat)

  2. Распакуйте новый архив поверх старой папки.
     Файл  server\.env  не трогайте: в нём пароль базы и настройки.

  3. Запустите  start.bat  снова.

  Новые таблицы в базе появятся сами при запуске. Недостающие библиотеки
  start.bat тоже доставит сам, из папки wheels - интернет не нужен.
  Данные остаются на месте.

  Если start.bat напишет "не удалось доставить библиотеки" - запустите
  install.bat: он пересоберёт окружение, база и настройки не пострадают.

  ВАЖНО: перезапуск обязателен. Страница читается с диска при каждом
  открытии, а сам сервер - нет. Если обновить файлы и не перезапустить,
  страница будет новая, а сервер старый, и новые разделы начнут отвечать
  ошибками вроде "Не удалось сохранить настройки".

  Приложение само это заметит: вверху появится жёлтая полоса
  "Страница обновлена, а сервер работает на старой версии".
  Увидели её - перезапустите start.bat.
