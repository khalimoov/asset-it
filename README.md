# Учёт ИТ-отдела

Система учёта техники ИТ-отдела: оборудование, ремонты, расходные материалы,
IP-адреса, пользователи. Работает в локальной сети предприятия, интернет не нужен.

Несколько учреждений в одной базе — у каждого свой учёт, свои справочники и свои
сотрудники; администратор видит сводку по всем сразу.

## Из чего состоит

| Что | Где |
|---|---|
| Весь интерфейс — одна страница | `it-inventory.html` |
| Сервер, права, работа с базой | `server/app.py` |
| Загрузка людей из Active Directory | `server/adsync.py` |
| Опрос адресов в сети | `server/netscan.py` |
| Схема базы и обновления | `server/schema.sql`, `server/migrations/` |
| Установка на сервер | `packaging/` |
| Как всё устроено и почему | `NOTES.md`, `server/README.md` |

Требуется PostgreSQL 14+ и Python 3.14 (64 бита, Windows).

## Запуск для разработки

```
cd server
copy .env.example .env      # вписать пароль базы
python app.py               # http://localhost:8000
```

Схема доводится до актуальной при каждом запуске — миграции идемпотентны.

## Сборка пакета для сервера

```
python packaging/build.py
```

Собирает `dist/asset-it-server` и архив рядом: страницу, сервер, .bat-файлы и
библиотеки Python в папке `wheels`. На сервере интернет не нужен — достаточно
распаковать, запустить `install.bat`, потом `start.bat`.

Подробности установки — в `packaging/УСТАНОВКА.txt`.

Та же команда собирает и `dist/asset-it-docker.zip` — пакет для Linux-сервера с Docker
(приложение + PostgreSQL, архив накладных в `/opt/asset-it/documents`). Из клона
репозитория образ поднимается напрямую: `cp .env.example .env`, вписать `PGPASSWORD`,
`docker compose up -d --build`. Подробности — `packaging/УСТАНОВКА-DOCKER.txt`.

Для сервера **без интернета** есть третий пакет с готовыми образами: на машине с Docker
и интернетом `sh packaging/build-offline.sh --debs noble` → `dist/asset-it-docker-offline.tar.gz`
(образы, compose, установщик, при `--debs` — ещё и .deb-пакеты самого Docker).
Инструкция — `packaging/offline/УСТАНОВКА-OFFLINE.txt`.

## Чего нет в репозитории

`server/.env` с паролем базы, собранный пакет `dist/`, датированные копии `backup/`.
Пакет пересобирается командой выше, `.env` создаёт `install.bat` при установке.
